These keep the plan as written unless you choose otherwise. RD1 is a blocker: plan-wrap will flag it again if it stays.

RD1Blocker

Where the scoreboard's game worker lives

Each scoreboard game runs in a small worker process that must load a specific bot version's code (bots.v7, bots.v13…). The plan puts that worker in src/orchestrator/. The project's own rules forbid that folder from importing bot versions, because it triggers an import loop. Scripts in scripts/ already do this safely.

Affects: step ES.2 and the scoreboard lane, which waits on this answer.
